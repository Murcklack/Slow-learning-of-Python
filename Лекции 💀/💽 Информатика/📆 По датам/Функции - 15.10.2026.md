# Функции
**Функция** - именнованный блок кода, выполняющий определённую задачу и который может быть вызван многократно
### Какие проблемы решает?
- Дублирование кода
- Сложность поддержки
- Читаемость и тестируемость
### Преимущества функций
- **DRY** - Don't Repeat Yourself
- Абстрация - скрываем детали
- Декомпозиция - разбивае задачу на подзадачи
- Тестируемость 
- Повторное использование
## Синтаксис 
Пример программы, которая приветствует пользователя:
```python
def greet(name):
	"""Возвращает имя с приветствием"""
	print(f"Привет {name}!")
greet("Анна") # Привет Анна!
greet("Artem") # Привет Artem!
help(greet) # Возвращает имя с приветствием
print(greet.__doc__) # Возвращает имя с приветствием
```
`name` - Параметр
`"Анна"` - Аргументр
```python
def имя_функции(параметр):
	"""Docstring"""
	тело функции
	return результат	
```
`Docstring` - строка документирования
- Оставить краткое описаие кода

## Scope. Области видисмости
### Локальная область (local)
```Python
def my_func():
	x = 10 # локальная переменная
	print(x)
my_func() # 10
print(x) # ошибка
```
### Глобальная (global)
```Python
y = 100

def read_global():
	print(y)

read_global() # 100
print(y) # 100
```
#### Поменять глобальную переменную из функции
```Python
y = 100

def read_global():
	global y
	y = 67
	print(y)

read_global() # 67
print(y) # 67
```

### Enclosing (объемлющая)
```Python
def outer():
	message = "Привет из внешней"
	def inner():
		print(message)
	inner()
outer()
```

# lambda функции
``` Python
def square(number):
	return number ** 2
# Одно и то же
lambda number: number ** 2
```
**Лямбда-функция(анонимная функция)** - это функция python, которая записывается в 1 строку и используется для бстрых операций
### Пример:
```Python
numbers = [1,2,3,4]
result = (list(map(lambda x: x + 10, numbers)))
```
