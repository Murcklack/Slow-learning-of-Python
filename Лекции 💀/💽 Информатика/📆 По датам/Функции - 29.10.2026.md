## Как вернуть много значений из функции
фибаначи возвращает 1 значение в виде массива
```Python 
def f(N):
    res = [1]
    for i in range(1, N):
        if i == 0: res.append(1)
        else:
            res.append(res[i-1] + res[i-2])
    return res
```
Возвращает много
```Python
def fib():
	a,b = 0, 1
	while True:
		yield a
		a, b = b, a + b
	
for i, f in enumerate(fib()):
	if i >= 10: break
	print(f)
```
Где: 
- **fib()** - функция генератор, вместо return `yield`
- **enumerate(fib())** - возвращает 2 значения (i и f)
- **break** - прекращает вызов функции

### Каждый вызов fib() - свой генератор
```Python
g = fib()
print(next(g)) # 0
print(next(g)) # 1 
g2 = fib()
print(next(g2)) # 0
print(next(g2)) # 1
```
### Конечный генератор
```Python
def meow(n):
    a = "a"
    n = 0
    while n < 3:
        yield a
        a += "meow"
        n += 1

print(list(meow(3)))
```

# Numpy
`numpy.arange()` - это встроенная функция Numpy, которя создаёт одномерный массив с равномерно расположенными значениями в заданном диапазоне
```python
arr1 = np.arange(5) # [0,1,2,3,4]
```
`numpy.linspace()` - это функция NumPy, которая создаёт одномерный массив из заданного количества равномерно распределённых чисел на заданном интервале
```Python
arr1 = np.linspace(0,10,num=5) # [0, 2.5]
```
