### Представление особых значений во float

**Таблица особых значений (стандарт IEEE 754)**

|**Экспонента (e)**|**Мантисса (m)**|**Значение**|
|---|---|---|
|Все нули|Все нули|$\pm0$|
|Все единицы|Все нули|$\pm\infty$ (Бесконечность)|
|Все единицы|Не все нули (любое)|**NaN** (Not a Number)|
|Все нули|Не все нули (любое)|**Субнормальное число**|

**Особенность представления дробей:**

`0.1` в десятичной системе $\neq$ точному представлению `0.1` во `float` (в двоичной системе это бесконечная периодическая дробь, из-за чего происходит потеря точности).

_Пример на C:_

```C
#include <stdio.h>
int main(void) {
    float b = 0.2;
    float a = 0.1;
    
    if (a + b == 0.3) {
        printf("+");
    } else {
        printf("-");
    }
    
    return 0;
}
```

**Результат:** `Error` (В выводе мы видим `-`, хотя логически должен быть `+`. Это классическая проблема погрешности арифметики с плавающей точкой).

### Представление текста в ЭВМ

#### **ASCII (7 бит)**
- Изначально $2^7 = 128$ символов.

#### **Ранние кодировки (8 бит)**

- 8 бит = 256 значений на 1 байт.
    
- **Кодовая таблица** — это таблица соответствия между числовыми кодами и символами.
    
- **Microsoft ANSI (Windows-125x):** Базовый ASCII (первые 127 символов) + дополнительные символы (128–255).
    

#### **Unicode**

Универсальный стандарт, включающий в себя:

- Латинские алфавиты
    
- Кириллицу
    
- Греческий алфавит
    
- Арабскую письменность
    
- Иврит
    
- Китайские, японские, корейские иероглифы
    
- Математические формулы, знаки, эмодзи и многое другое.
    

Каждому символу присвоено своё уникальное значение.

🔗 _Актуальная табличка с символами:_ [symbl.cc/ru/unicode-table](https://symbl.cc/ru/unicode-table/)

#### **UTF-8**

Стандарт кодирования символов, который основан на Unicode и является самым распространенным в сети.

- **Память:** Имеет переменную длину. Один символ занимает **от 1 до 4 байт** памяти в зависимости от языка (например, базовая английская латиница занимает 1 байт, кириллица — 2 байта, эмодзи — 4 байта).

_Пример: Заглавная буква «Б»_

- **Unicode:** `U+0411` = `411` в 16-ричной системе = `100 0001 0001` в двоичной
    
- **UTF-8 (hex):** `D0 91`
    
- **UTF-8 (Десятичные байты):** `208 145`
    
- **UTF-8 (Бинарно):** `11010000 10010001`
    

> [!warning] Важно
> 
> **Не путать шрифты и кодировку!** Кодировка отвечает за то, какой числовой код соответствует букве в памяти компьютера, а шрифт — только за визуальное (графическое) отображение этого кода на экране.
