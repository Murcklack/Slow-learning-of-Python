# В python нет переменных
В Python есть переменные в обычном практическом смысле, но технический - это не контейнер, а имя связанное с объектом

**Объекты** - это абсолютно всё, что программа может сохранить в память, передать куда-то или связать именем
**Переменная** - это имя, которое ссылается на объект
### Присваивание
`a = 4000`
Python делает 2 вещи:
 1. Создаёт объект 4000. Объект существует сам по себе, у него есть уникальный **id**, и он живёт, пока ссылка на него существует.
2. что то ещё
### Как посмотреть id
Использовать функцию `id()`
```python
a = 4000
b = 30

print(id(a), id(b))
```

### Скрытый счётчик ob_refcnt
У каждого объекта в питоне в куче есть скрытое поле - **счётчик ссылок**. Каждый раз, когда вы создаёте ссылку, счётчик увеличивается. Если счётчик ссылок на объект == 0, то он удаляется из памяти

## Как избавиться от имени? 
`del <имя>`
```python
a = 123
b = 24

c = a
a = b
b = c
del c
```

### Как посмотреть тип данных?
`type()` - функция которая возвращает тип данных объекта в скобках
```python
a = 1
s = "Yo"

print(type(a))
print(type(s))
```
**Вывод**: 
```
<class 'int'>
<class 'str'>
```

 - Индексация

>[!warning] Нельзя присвоить символ по индексу.

### Регистр
```python
s = "Hello world"

s.upper() #HELLO WORLD
s.lower() #hello world
s.capitalize() #Hello world - первый символ с заглавной
s.title() #Hello World - каждое слово после пробела поднимается
s.swapcase() # hELLO WORLD - меняет регистр
```
### Поиск и проверка
```python
s = "Hello world"

s.find("World") # 6 - индекс начала, или -1 если не найдено
s.rfind("l") #9 - последнее входящее
s.index("World") #6 - как find
s.count("l") #3 - сколько l 
```
### Замена
`s.replace("l", "L")`
### Обрезка пробелов
`s.strip()` - с обоих концов
`s.lstrip()` - только слева
`s.rstrip()` - только справа
`"xxhellox".strip("x")` - по бокам удаляет x

### Выравнивание и заполнение
```python
s = "hi"

s.center(10)
s.ljust(10)
s.rjust(10)
s.zfill(5)

"42".zfill(5) # "00042"
"hi".center(10, "*") # "****hi****"
```
