# Определение
**Списки** в Python - это упорядоченные изменяемы коллекции, которые хранят элементы любых типов данных
- упорядоченные 
- изменяемые
>[!warning] Списки это не массивы!

# Взаимодействие со списками
### Срезы
```Python
fruits = ['Яблоко', 'Банан', 'Вишня']
print(fruits[0])
print(fruits[-1])
```
Вопрос 1:
- []
- [2, 3]
```Python
meow = ["lol", "ahh", "guffu"]

```
### Добавить
```Python
todo = []
todo.append("купить хлеб")
todo.append("Позвонить возлюбленной")
todo.insert(1, "Выпить кофе")
print(todo) # ['купить хлеб', 'Выпить кофе', 'Позвонить возлюбленной']
```
### Забрать
```Python
todo.remove("Выпить кофе")
last = todo.pop()
print(last,todo)
```

```Python
todo.extend(["убрать", "почитать"])
```

### Сортировка
```Python
numbers = [1,2,3,4,5,1,1,1,1]
numbers.sort()
print(numbers)
```
Сортировка по **не убыванию**
```Python
numbers = [1,2,3,4,5,1,1,1,1]
numbers.sort(reverse=True)
print(numbers)
```
Сортировка по **не возрастанию**
```Python
numbers = [1,2,3,4,5,1,1,1,1]
numbers.reverse()
print(numbers)
```
**Переворот**
```Python
numbers = [1,2,3,4,5,1,1,1,1]
numbers.clear()
print(numbers)
```

### Копирование
```Python
a = [1, 2, 3]
b = a.copy() # 1 метод
b = list(a) # 2 метод
b = a[:] # 3 метод
  
a.append(100)
b.append("AAA")
b.remove(2)
print(a, b)
print(id(a), id(b))
```
С простыми списками можно так
```Python
import copy

a = [[1,2], [3,4]]
b = copy.deepcopy(a)
a[0].append(99)

print(a)
print(b)
```
**Глубокое копирование**, дабы были 2 полностью независимые копии
# **For** для списка
Перебор всех элементов:
```Python
lol = ["кот", "мяу", "XD"]

for i in a:
	print(lol) # Выйдут все элементы списка поочерёдно
```
Можно через индексы:
```Python
lol = ["кот", "мяу", "XD"]

for i in range(len(lol)):
	print(lol[i]) # Выйдут все элементы списка поочерёдно
```
### Генераторы списков
Задача создать список: [0,1,4,9,16...]
```Python
L = [i*i for i in range(10)]
```
Можно с условием
```Python
[выражение for элемент in iterable if условие]
nums = [1,2,3,4,5,6]
evens = [x for x in nums if x % 2 == 0]
print(evens)
```
ещё так
```Python
nums = [1,2,3,4,5,6]
numbers = ["chet" if x % 2 == 0 else "нечёт" for x in nums]
print(numbers )
```
